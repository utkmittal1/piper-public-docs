Piper browses the web in a browser of its own, a copy of Chromium it downloads into its data folder on your Mac. It opens pages there, reads them, clicks, and fills forms. When a page needs a sign-in, Piper stops and asks you to sign in through a card in the conversation. After you sign in, Piper stays signed in to that site for later tasks.

Piper can also work in the Chrome you use yourself, on sites you're already signed into there. That access starts switched off.

This page covers how to:

- [Set up Piper's own browser](#pipers-own-browser) and see where it keeps a sign-in
- [Know when Piper asks](#when-piper-asks-before-it-acts-on-a-page) before it acts on a page, and how far one approval reaches
- [Sign in to a site](#sign-in-to-a-site) through the sign-in card
- [Use the Chrome you already use](#use-the-chrome-you-already-use), and see why Piper still asks every time
- [Compare the two browsers](#which-browser-piper-uses)

## Piper's own browser

Piper's browser runs hidden, with no window, while Piper works. Piper runs every conversation in the same browser, with separate pages for each conversation, so two tasks can browse at the same time without interfering. Piper blocks ad networks and trackers on every page it opens. When a conversation has gone quiet for a while, Piper closes that conversation's pages.

That browser starts empty and stays separate from the browsers you use yourself. Once a task is over, Piper keeps only the sign-ins you gave through the sign-in card. Piper collects the cookies and stored site data from the window you signed in through and keeps them in a file in its own data folder. Piper seeds every later conversation's browser from that file.

Piper turns browsing on for a new install. When you switch browsing off, Piper turns it off for every conversation. To turn it off, open **Settings**, then **Built-in tools**, and clear the checkbox on **Browse websites**.

<Note>
  Piper downloads the browser once, in the background, the first time Piper runs. Until the download finishes, Piper can't open a page or show you a sign-in window.
</Note>

<Warning>
  Once you sign in to a site, Piper stays signed in to it. Piper has no screen for reviewing, listing, or removing a saved website sign-in, so you can't sign out of a single site from Piper's interface. The only way to clear a saved sign-in is to delete Piper's whole data folder, which takes your tasks, files, and memory with it. See [Your data stays local](/control/your-data-stays-local) for what that folder holds.
</Warning>

## When Piper asks before it acts on a page

On an ordinary page, Piper works without asking. Piper asks you first on a page it holds a saved sign-in for, because Piper acts as you on that page.

Each answer covers a different scope.

| Your answer | What it covers |
|---|---|
| **Allow** | The rest of that one request on that site. Your next message starts the question over |
| **Always allow in this conversation** | That kind of action for the rest of the conversation, on any site. Piper saves your answer, and the answer still applies after you quit and reopen the app |

On **Autopilot**, Piper approves the action itself and stops asking in that conversation.

Piper decides page by page whether to ask, by checking whether it holds a sign-in for that site. For that reason, **Built-in tools** in **Settings** shows **Always runs** beside browsing, where other capabilities offer **Auto** and **Ask**. See [Approvals and permissions](/control/approvals-and-permissions) for Manual, Autopilot, and what each answer means.

<Note>
  A scheduled task's runs, a long-running task's steps, and the tasks Piper starts on its own use Piper's own browser with the sign-ins you've already saved. Piper keeps these tasks out of your own Chrome and away from the sign-in card, because nobody is there to answer. To let such a task reach a site that needs a sign-in, sign in to that site from a conversation of your own first.
</Note>

## Sign in to a site

When Piper reaches a page that shows its contents only after you sign in, Piper puts a **Sign in needed** card in the conversation, naming the site.

<Steps>
  <Step title="Open the window">
    Select **Open sign-in window**. Piper opens a visible browser window on that site, and keeps its hidden browser running behind the window.
  </Step>
  <Step title="Sign in as you normally would">
    Type your credentials into the site itself. Piper does not read what you type, and it never asks you for a password.
  </Step>
  <Step title="Tell Piper you are done">
    Select **I've signed in**. Piper closes the window, saves the sign-in, and picks the task back up on its own.
  </Step>
</Steps>

If you close the window yourself, Piper saves the sign-in the same way. The card then reads **Signed in**. Select **Continue** to resume the task. Either way, Piper stays signed in to that site, for this task and every task after it.

If you don't finish signing in in time, Piper closes the window and the card reads **Window closed**. Select **Open sign-in window** to start again. Where Piper could not save the sign-in, the card reads **Sign-in not saved** with the reason, and you select **Try again** to reopen the window.

<Note>
  Select **Dismiss** to put the card away. Piper removes the **Open sign-in window** button with the card and keeps waiting. Ask Piper in the message box to try the page again, or tell Piper to carry on without that site.
</Note>

## Use the Chrome you already use

Piper can work in your own Chrome instead, on sites you're already signed into there. This access starts switched off. Once you switch it on, it applies to every conversation. It needs one piece of setup: you install the Playwright extension, published by Microsoft, from the Chrome Web Store. Piper attaches to your running Chrome through that extension.

<Steps>
  <Step title="Find the setting">
    In **Settings**, select **Built-in tools**. **Use my Chrome for sites I’m signed in to** sits under **Browse websites** and shows only while browsing is on. Its checkbox stays unavailable until the extension is in place, and the line beneath it reads **Needs a one-time setup. Piper still asks you each time.**
  </Step>
  <Step title="Start the setup">
    Select **Set up**. Piper explains that it works in your Chrome through an extension published by the Playwright team at Microsoft, and offers **Install extension**.
  </Step>
  <Step title="Install it in Chrome">
    Select **Install extension**. Piper opens the Playwright extension's page in the Chrome Web Store, where you add it to Chrome the way you would any other extension.
  </Step>
  <Step title="Come back to Piper">
    Piper checks for the extension while you're away and switches the setting on once the extension is installed. Piper does this when you started the install from this setting or from Piper's sign-in card. Piper looks for the extension in Chrome's own profile folder on disk, so Chrome can be closed.
  </Step>
</Steps>

Piper also offers this from a card above the message box, right after you sign into a site through the sign-in card. Select **Set this up** to begin, or **Use my Chrome** where the extension is already installed. Select **Not now** to leave it for a later sign-in, or **Don’t ask again** to stop Piper offering it. The setting stays on the **Built-in tools** page either way.

<Note>
  This works with Google Chrome only. Piper looks for the extension in Chrome's own profile folder, so installing it in another browser built on Chromium does not turn the setting on. Where the extension is installed but switched off in Chrome, Piper says so and the setting stays unavailable until you turn the extension back on there.
</Note>

<Warning>
  Piper asks you before every request it makes in your Chrome, even in Autopilot. Piper offers no **Always allow in this conversation** for your own browser. Your yes covers the rest of that one request on that site, and your next message starts the question over. A scheduled task's runs, a long-running task's steps, and the tasks Piper starts on its own stay out of your own Chrome, because nobody is there to answer.
</Warning>

## Which browser Piper uses

| | Piper's own browser | Your Chrome |
|---|---|---|
| Where it runs | A separate Chromium in Piper's data folder | The Chrome you use yourself |
| Visible | No, except the sign-in window | Yes, it is your browser |
| Signed in to | Only sites you signed into through the sign-in card | Whatever that Chrome profile is signed into |
| Asks first | On a site Piper holds a sign-in for | Every request |
| Can you make it stop asking | Yes, with **Always allow in this conversation** or Autopilot | No |
| On for a new install | Yes | No |
| Used by a task running on its own | Yes | No |

<Note>
  Piper's plain web search and page fetch are a separate tool, **Web search & fetch**, under **Settings**, then **Built-in tools**. That tool uses neither browser. Piper falls back to a browser when a fetch is blocked or misses content the page shows a person.
</Note>
