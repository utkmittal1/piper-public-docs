---
title: "Web and sign-ins"
description: "How Piper opens real web pages in its own browser, how signing in once through the sign-in card keeps Piper signed in to that site, and how to let Piper work in the Chrome you already use."
---

Piper browses the web in a browser of its own: a copy of Chromium it downloads into its data folder on your Mac. It opens pages there, reads them, clicks, and fills forms. When a page requires a sign-in, Piper stops and asks you to sign in through a card in the conversation. Once you have, Piper stays signed in to that site for later tasks.

## Piper's own browser

Piper's browser runs out of sight, so no window appears while Piper works. Every conversation connects to the same browser and gets its own pages inside it, which is how two tasks can browse at the same time.

That browser starts with nothing loaded and knows nothing about the browsers you use yourself. It reaches an account only where you signed in through the sign-in card, and it keeps the cookies those sites hand it in a file of its own that survives the task.

Browsing is on for a new install. To turn it off, go to **Settings** > **Tools** and untick **Browse websites** under **Core Tools**.

<Note>
  Piper downloads the browser in the background the first time it runs, about 360 MB, once. Until that finishes, Piper cannot open a page or show you a sign-in window.
</Note>

## When Piper asks before it acts on a page

On an ordinary page Piper works on its own. On a page you are signed in to it asks you first, because that page is your account. Approving covers the rest of that one request on that site, and the next thing you ask starts the question over.

Browsing has no **Auto** or **Ask** setting of its own, which is why **Settings** > **Tools** shows **Always runs** beside it. Piper makes that call page by page instead, on whether you are signed in to the site.

## The sign-in card

When Piper meets a login wall, it puts a **Sign in needed** card in the conversation, naming the site.

<Steps>
  <Step title="Open the window">
    Select **Open sign-in window**. Piper opens a real browser window on that site, and its hidden browser keeps running behind it.
  </Step>
  <Step title="Sign in as you normally would">
    Type your credentials into the site itself. Piper does not read what you type, and it never asks you for a password.
  </Step>
  <Step title="Tell Piper you are done">
    Select **I've signed in**. Piper closes the window, saves the login, and picks the task back up on its own.
  </Step>
</Steps>

Closing the window yourself works too. The card then reads **Signed in**, and you select **Continue** to set Piper going again. Either way Piper stays signed in to that site, for this task and every later one.

Piper closes the window five minutes after it opens if you have not finished by then, and the card reads **Window closed**. Select **Open sign-in window** to start again.

<Note>
  Select **Dismiss** to put the card away. That takes the **Open sign-in window** button with it, and Piper is still waiting, so either ask it in the message box to try the page again or tell it to carry on without that site.
</Note>

<Warning>
  Once you sign in to a site, Piper stays signed in to it. There is currently no way to sign out of a single site from Piper's own interface.
</Warning>

## Using the Chrome you already use

Piper can work in your own Chrome instead, on sites you are already logged into there, so you skip signing in again. This is off until you turn it on, and it needs one piece of setup. Piper attaches to the Chrome you are already running through an extension, published by the Playwright team at Microsoft, that you install from the Chrome Web Store.

<Steps>
  <Step title="Find the setting">
    In **Settings**, select **Tools**. Under **Core Tools**, find **Use my Chrome for sites I'm signed in to**, which sits under **Browse websites** and shows only while browsing is on. Its tick box stays greyed out until the extension is in place, and the line beneath it reads **Needs a one-time setup. Piper still asks you each time.**
  </Step>
  <Step title="Start the setup">
    Select **Set up**. Piper explains that it works in your Chrome through an extension published by the Playwright team at Microsoft, and offers **Install extension**.
  </Step>
  <Step title="Install it in Chrome">
    Select **Install extension**. Piper opens the Playwright Extension page in the Chrome Web Store, where you add it to Chrome the way you would any other extension.
  </Step>
  <Step title="Come back to Piper">
    Piper watches for the extension while you are away and ticks the setting itself once it lands, so there is nothing left to switch on by hand. The check reads Chrome's own profile folder, so Chrome does not have to be running for Piper to see it.
  </Step>
</Steps>

You can also turn it on from a card above the message box, which Piper offers right after you sign into a site through the sign-in card. Select **Set this up** to begin, or **Use my Chrome** where the extension is already installed. **Not now** leaves it for a later sign-in, and **Don't ask again** stops the offer for good. The setting stays on the **Tools** page either way.

The first time Piper attaches, Chrome itself asks you to pick a tab to share. Answer it once and later connections go through without the question.

<Note>
  This works with Google Chrome only. Piper looks for the extension in Chrome's own profile folder, so installing it in another browser built on Chromium does not turn the setting on. If the extension is installed but switched off in Chrome, the setting stays unavailable until you turn it back on there.
</Note>

<Warning>
  Piper asks you before it works in your Chrome, and that permission never becomes standing. There is no **Always allow** button for your own browser, and Autopilot mode still stops to ask. Your yes covers the request you are answering and nothing after it.
</Warning>

## Which browser Piper uses

| | Piper's own browser | Your Chrome |
|---|---|---|
| Where it runs | A separate Chromium in Piper's data folder | The Chrome you use yourself |
| Visible | No, except the sign-in window | Yes, it is your browser |
| Signed in to | Only sites you signed into through the sign-in card | Everything you are signed into |
| Asks first | On a site you are signed in to | Every request, and never remembered |
| On for a new install | Yes | No |
