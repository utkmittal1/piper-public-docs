Response style is a set of four controls for how Piper writes back to you: how long a reply runs, what tone it takes, how much structure it uses, and whether it uses emoji. Set them once and every session follows them.

## Where the controls live

In **Settings**, select **Instructions**. The four controls sit at the top of that page, under **Communication Style**.

Selecting an option saves it straight away. There is no save button, and the change reaches sessions already open on your next message in them.

Each custom agent has its own four controls. Open **Settings**, select **Custom Agents**, choose an agent, then open its **Instructions** tab. A change there applies to that agent alone, and no session runs on those controls today. "How this relates to instructions" below covers that limit.

## The four controls

| Control | Options | Starts on |
|---|---|---|
| **Response Length** | Concise, Balanced, Detailed | Balanced |
| **Tone** | Formal, Neutral, Casual | Neutral |
| **Formatting** | Structured, Balanced, Prose | Balanced |
| **Emoji** | None, Occasional | Occasional |

### Response length

- **Concise.** Piper leads with the answer or the action taken and cuts the preamble. One sentence stays one sentence.
- **Balanced.** The length matches the question. A simple question earns a few sentences, a complex one earns a few paragraphs.
- **Detailed.** Piper gives context before the specifics, walks through the steps, and answers the obvious follow-up questions before you ask them.

### Tone

- **Formal.** Complete sentences, no contractions, no slang, the register of business correspondence.
- **Neutral.** Direct and professional, with contractions where they sound natural. Neither stiff nor chatty.
- **Casual.** Relaxed and conversational, the way a sharp colleague talks. Light humor is fine, forced enthusiasm is not.

### Formatting

- **Structured.** Piper formats for scanning: headings, bullets, numbered steps, tables, and bold key terms, so the gist comes through from the headings alone.
- **Balanced.** The content picks the form. Three items live in a sentence, five options belong in a table, a concept belongs in a paragraph.
- **Prose.** Connected paragraphs, with headings and bullets kept to a minimum, closer to a well-written memo.

### Emoji

- **None.** No emoji in Piper's own replies, status updates, or summaries.
- **Occasional.** Emoji used rarely and with purpose: a status marker, a section cue, a touch of warmth.

## How this relates to instructions

The style controls and your [standing instructions](/context/instructions-and-profile) share the same Settings page and reach the same sessions. Use the controls for length, tone, formatting, and emoji. Put everything else in **Custom Instructions**.

Piper has no control for choosing a custom agent for a task. Every session runs the built-in agent, named **Piper**, so these four controls and your **Custom Instructions** set the style of every reply you get. A [custom agent](/autonomous/custom-agents) keeps its own four controls, and no session runs on them. Your memory and your profile reach every session.
