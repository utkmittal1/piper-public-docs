An AI provider is the service that runs the AI model Copus works with. Copus is the assistant you talk to, and Copus sends each turn of the conversation to the provider. Copus needs at least one provider set up before it can run a task.

You set up a provider in one of two ways. You sign in to Claude Code or Codex, or you add an API key for Anthropic, OpenAI, or DeepSeek.

This page covers how to:

- [Find the providers in Settings](#find-the-providers-in-settings), split into agents and model APIs
- [Sign in to Claude Code or Codex](#sign-in-to-claude-code-or-codex)
- [Add an API key](#add-an-api-key) for Anthropic, OpenAI, or DeepSeek
- [Choose the provider a task runs on](#choose-the-provider-a-task-runs-on)
- [Set the default provider](#what-the-default-controls) for the work Copus starts on its own

## Find the providers in Settings

Open **Settings**, then **AI Providers**. Copus groups the providers by how you connect them.

Claude Code and Codex sit under **Agents**. Each card shows a status: **Signed in**, **Not signed in**, or **Can't be used on this computer**. Select a card to open its panel, where you sign in and set the default. To change accounts, sign in again, and Copus replaces the credential it holds.

Anthropic, OpenAI, and DeepSeek sit under **Model APIs**. Each card shows **API key saved** or **No API key**. Select a card to add, update, or remove its key, and to see its **Available models**. Copus checks a new key with the provider before it saves the key, then offers that provider's models.

## Sign in to Claude Code or Codex

<Steps>
  <Step title="Open Claude Code or Codex">
    Under **Agents**, select **Claude Code** or **Codex**.
  </Step>
  <Step title="Sign in">
    Select **Sign in**. For Claude Code, select **Open the sign-in page**, approve Copus in your browser, paste the code your browser shows you into **Paste the code here**, and select **Submit code**. For Codex, Copus opens a browser window and waits for you to finish signing in there.
  </Step>
  <Step title="Make it the default if you want">
    Turn on **Use as default** to run the work Copus starts on its own on this provider. See [What the default controls](#what-the-default-controls).
  </Step>
</Steps>

If you don't finish signing in within a few minutes, Copus ends the sign-in and shows **This sign-in expired. Start again.** Select **Sign in** to start a new sign-in.

## Add an API key

<Steps>
  <Step title="Open the provider">
    Under **Model APIs**, select **Anthropic**, **OpenAI**, or **DeepSeek**.
  </Step>
  <Step title="Add the key">
    Paste the key into the field under the **API key** heading, then select **Save key**. Select **Where do I get a key?** to open the provider's signup page.
  </Step>
  <Step title="Check the models">
    Once Copus accepts the key, the card reads **API key saved** and the panel lists the **Available models**. Copus offers a model only where Copus supports it and your account can reach it, so you see a shorter list with a key on a lower tier.
  </Step>
  <Step title="Make it the default if you want">
    Turn on **Use as default** to run the work Copus starts on its own on this provider.
  </Step>
</Steps>

Copus keeps the API key in your Mac's system keychain. Select **Update key** to replace the key, or **Remove key** to delete it. Copus asks you to confirm, then deletes the key and stops offering that provider's models. You can add the key again at any time.

## Choose the provider a task runs on

Under the message box, Copus shows the provider and the model a task runs on, separated by a dot. When the chat is narrow, Copus shows only the model, and you can hover over the model name to see both. Select the provider or model name to pick a different provider or model, including part way through a conversation.

Many models also have effort levels, which set how much reasoning the model does before it answers. Point at a model in the list to open its levels beside it: **Default**, or a level such as **Low**, **Medium**, or **High**. With **Default**, the provider picks the level. When you select the model itself, Copus picks **Default**, or **Medium** for a model with no **Default**. For a model with only one level, Copus shows no list of levels.

A new task opens on the provider, model, and level you picked last, even when another provider is marked **Default**. If you've never picked a provider, Copus opens a new task on the first provider in the list whose models Copus already knows.

A task keeps the provider it started on, even after you change your default. A scheduled or multi-step task runs on the provider and model of the conversation you set it up in.

## What the default controls

Copus runs the work it starts on its own on the provider marked **Default**. That work includes the tasks on the Home page and Copus's checks of your mail and calendar. See [Work Copus starts before you ask](/working/before-you-ask).

[Ask Copus](/working/describing-what-you-need#ask-copus-a-quick-question) also runs on the default provider. Copus picks the provider at the first message of an **Ask Copus** conversation, and keeps that provider until you select **Clear** in the **Ask Copus** panel.

To move the default, turn on **Use as default** for another provider. One provider is always the default.

If a task is running when you change the default, Copus opens **Change the default while a task is running?**. Select **Change it anyway** to switch, or close the dialog to keep the current default. When you switch, Copus stops every task running at that moment. To carry a task on, send another message, and Copus picks the task up on the provider it was already running on.
